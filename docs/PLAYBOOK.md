# پیاده‌سازی مرحله‌به‌مرحله — دستورهای تست برای کاربر

این فایل فقط برای «چطور کدها را به‌روز کنم و کجا ببینم» است. هیچ دستوری اینجا لازم نیست حفظ شود؛
در پایان هر فاز، دقیقاً همان دستورهای لازم در چت نوشته می‌شود.

## ۰) یک نکته درباره‌ی برنچ‌ها

تا وقتی تأیید نکنی، کدِ فاز جدید روی `main` نمی‌آید. برای تست کردن، به‌جای `git pull` این را بزن
(اسم برنچ را در چتِ همان فاز می‌نویسم):

```powershell
git fetch origin
git checkout phase-2-i18n-formats
git pull
```

وقتی تأیید کردی، همه‌چیز به `main` منتقل می‌شود و دفعه‌ی بعد فقط `git pull` کافی است.

## ۱) به‌روزرسانی کدها (هر بار که فاز جدیدی تمام شد)

در پوشه‌ی پروژه (روی ویندوز: کلید `Shift` را نگه‌دار، راست‌کلیک روی فضای خالی پوشه →
«Open PowerShell window here» / «باز کردن پنجره‌ی اینجا»):

```powershell
git pull
npm install
```

اگر `npm install` چیزی نصب نکند، فقط یک خط ساده نشان می‌دهد و تمام — این طبیعی است.

## ۲) بالا آوردن پروژه

```powershell
npm run dev
```

وقتی این خطوط را دیدی یعنی آماده است:

```
▲ Next.js 15.5.25
- Local: http://localhost:3000
✓ Ready in ...
```

برای خاموش کردن: در همان پنجره کلیدهای `Ctrl` + `C`.

## ۴) قاعده‌ی رفرش

بعد از هر بار `git pull`، در مرورگر یک بار `Ctrl` + `Shift` + `R` بزن (ریفرش کامل).
اگر صفحه سفید یا خطا داد، `npm run dev` را با `Ctrl` + `C` ببند و دوباره باز کن.
اگر باز هم درست نشد، این دو خط را بزن و دوباره `npm run dev`:

```powershell
Remove-Item -Recurse -Force .next
npm run dev
```

## ۵) زبان را کجا عوض کنم؟

دکمه‌ی `EN | فارسی` در گوشه‌ی چپِ نوار بالای صفحه (حالت فارسی: گوشه‌ی راست) است. یک بار کلیک کن؛
صفحه با همان مسیر ولی در زبان دیگر باز می‌شود و انتخابت در کوکی ذخیره می‌شود، پس اگر آدرس
`http://localhost:3000` را تنهایی هم باز کنی، همان زبان را می‌بینی.

## ۶) هر بار که فازی تمام شد، چه چیزی در چت می‌نویسم؟

چهار چیز، همیشه:
1. چه چیزی ساخته/اصلاح شده (فارسی ساده).
2. دستورهای دقیق: `git fetch` / `git checkout` / `git pull` → `npm install` → `npm run dev`.
3. آدرس یا آدرس‌هایی که باید باز کنی و آنچه باید در هر کدام ببینی.
4. **جدول چک‌لیست**: هر بندِ قابل‌تست در یک ردیف، با «کجا را ببینی» و «چه چیزی نشانه‌ی قبولی است».
   هر ردیفی که در این جدول نباشد، یعنی در آن فاز ساخته نشده — پس اگر موردی را جا افتاده دیدی،
   همان شماره‌ی ردیف را بگو.
